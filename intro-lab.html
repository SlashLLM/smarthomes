Intro Lab

Four opening films for the homepage. Each one lands on the live hero with no visible cut. Replay any card, switch to phone size, or open one full screen. The default is set by INTRO_DEFAULT in index.html.

A · Original ~11s

The current film: letterboxed and desaturated. Tenancy pain points fall in as cards, a sweep turns them into SmartHomes benefits, the income counter climbs, and a title card resolves into the site.

B · Aperture ~7s

Architectural restraint. A terracotta hairline opens into a window onto the house. Two quiet lines, "Every home has a second income. Most owners never see it.", sit beside one proof card counting long-term to short-stay income. Then the window widens into the hero.

Reference: Kononenko Architectural Bureau (small type anchored bottom-left, generous negative space).

C · Ledger ~8s

An editorial owner report on espresso. Three ruled rows count up the proof ($14.2M paid out, 83% occupancy, +167% uplift). The page then splits open like doors onto the house, and an oversized SmartHomes wordmark rises over the photo.

Reference: Velora Home (giant wordmark overlapping a full-bleed photo), Serpentine (line reveals).

D · Split default · ~7s

The whole pitch in one frame. The same house, run two ways: a grey "long-term let" half against a warm "managed short-stay" half, both incomes counting up. The divider then sweeps the long-term side away, ending on "+193% · same keys, same house".

Reference: before/after comparison sliders, done cinematically.
